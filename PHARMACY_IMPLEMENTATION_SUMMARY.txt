## API Endpoints (11 total)

| Method | Endpoint | Role | Purpose |
|--------|----------|------|---------|
| POST | `/pharmacy/medicines` | Admin, Pharmacist | Create medicine |
| GET | `/pharmacy/medicines` | Admin, Doctor, Nurse, Pharmacist | List medicines (paginated, searchable) |
| GET | `/pharmacy/medicines/low-stock` | Admin, Pharmacist | Get medicines below reorder level |
| GET | `/pharmacy/medicines/expiring` | Admin, Pharmacist | Get medicines expiring in 30 days |
| GET | `/pharmacy/medicines/:id` | Admin, Doctor, Nurse, Pharmacist | Get single medicine |
| PATCH | `/pharmacy/medicines/:id` | Admin, Pharmacist | Update medicine |
| DELETE | `/pharmacy/medicines/:id` | Admin, Pharmacist | Soft delete medicine |
| PATCH | `/pharmacy/medicines/:id/stock` | Admin, Pharmacist | Add/remove stock |
| POST | `/pharmacy/dispense` | Admin, Pharmacist | Dispense medication (with history tracking) |
| GET | `/pharmacy/dispense/:prescription_id` | Admin, Doctor, Pharmacist | Get dispense history |

## Testing the Endpoints

All endpoints are now ready to test:

```bash
# Create medicine
curl -X POST http://localhost:8080/api/v1/pharmacy/medicines \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Paracetamol",
    "dosage": "500mg",
    "price": 5.50,
    "manufacturer": "Cipla Ltd",
    "batch_number": "BAT001",
    "expiry_date": "2025-12-31",
    "stock_quantity": 1000,
    "reorder_level": 20
  }'

# List medicines
curl -X GET "http://localhost:8080/api/v1/pharmacy/medicines?page=1&limit=10&search=paracetamol" \
  -H "Authorization: Bearer TOKEN"

# Get low stock
curl -X GET "http://localhost:8080/api/v1/pharmacy/medicines/low-stock" \
  -H "Authorization: Bearer TOKEN"

# Get expiring
curl -X GET "http://localhost:8080/api/v1/pharmacy/medicines/expiring" \
  -H "Authorization: Bearer TOKEN"

# Update stock
curl -X PATCH "http://localhost:8080/api/v1/pharmacy/medicines/{id}/stock" \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "quantity": 100,
    "reason": "new_purchase"
  }'

# Dispense medication
curl -X POST "http://localhost:8080/api/v1/pharmacy/dispense" \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "prescription_id": "uuid",
    "staff_id": "pharmacist_uuid"
  }'
```
